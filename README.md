# ShopFloorPlanner

macOS-приложение для проектирования производственных цехов металлообработки с расчётом времени изготовления деталей.

## Основной функционал

### 2D-схема цеха
- Визуальный редактор планировки цеха (drag & drop)
- Библиотека оборудования: токарные, фрезерные, сверлильные, шлифовальные станки, сварочные посты и др.
- Расстановка рабочих мест, складских зон, проходов
- Масштабирование и экспорт схемы (PDF, PNG)

### Расчёт времени изготовления
- Маршрутная карта детали: последовательность операций
- Нормирование каждой операции (основное + вспомогательное время)
- Учёт переналадки оборудования
- Расчёт машинного времени по режимам резания

### Внутрицеховая логистика
- Расчёт времени транспортировки между станками
- Оптимизация маршрута детали по цеху
- Учёт очерёдности и загрузки оборудования

### Итоговые расчёты
- Полное время изготовления от заготовки до готовой детали
- Диаграмма Ганта по операциям
- Узкие места (bottleneck) в производственном цикле

## Стек технологий
- **Язык:** Swift
- **UI:** SwiftUI + AppKit
- **2D-графика:** SpriteKit / Core Graphics
- **Данные:** Core Data / SQLite
- **Платформа:** macOS 13+

## Структура проекта

```
ShopFloorPlanner/
├── App/                    # Точка входа, AppDelegate
├── Models/                 # Модели данных (станки, детали, операции)
├── Views/                  # SwiftUI-вьюхи
│   ├── FloorEditor/        # Редактор 2D-схемы
│   ├── PartPlanner/        # Маршрут детали
│   └── Reports/            # Отчёты и расчёты
├── Services/               # Логика расчётов
│   ├── TimeCalculator/     # Расчёт времени операций
│   └── RouteOptimizer/     # Логистика внутри цеха
├── Resources/              # Иконки, шрифты, локализация
└── Tests/                  # Юнит и UI тесты
```
